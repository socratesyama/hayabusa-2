# はやぶさ2用語集(サイト制作用)

一般向けサイトで説明に使える用語をまとめた。表現は必要に応じてやさしく調整すること。

## 天体・科学用語

- **リュウグウ(Ryugu)**: はやぶさ2が探査したC型(炭素質)小惑星。正式名162173 Ryugu。平均直径約900m。竜宮城にちなむ。
- **C型小惑星**: 炭素質隕石に似た組成を持つ、暗くて水・有機物を多く含む小惑星。地球の水や生命の起源を探る鍵。
- **S型小惑星**: 「はやぶさ」が探査したイトカワなどの種類。リュウグウ(C型)と対比される。
- **トップシェイプ**: 上と下のすり鉢を合わせたような、そろばんの珠に似た形状。高速自転と岩の移動で形成される。
- **レゴリス**: 小惑星・月などの表面を覆う砂や細かい岩石。リュウグウ表面は岩ばかりでレゴリスがほとんどない。
- **ボルダー(岩塊)**: リュウグウ表面に散在する大小の岩。最大のもの(オトヒメ)は幅約100m級。
- **クレーター**: 隕石衝突などでできた窪み。リュウグウ最大のウラシマクレーターなどがIAU認定。
- **サクスム(Saxum)**: リュウグウの地名申請で新設された「ボルダー(岩)」の地形タイプ。
- **CIコンドライト**: 最も始原的な炭素質隕石のグループ。リュウグウ試料の組成はこれに最も近い。
- **アミノ酸**: 生命のタンパク質の材料。リュウグウ試料から10種以上が検出された。
- **核酸塩基**: DNA/RNAを構成する分子。リュウグウからウラシルが検出された。
- **空隙率**: 体積に対する隙間の割合。リュウグウは約50〜60%と隙間だらけ。
- **熱慣性**: 物体の温度の変化にくさ。リュウグウ表面は熱慣性が低く、昼と夜で温度差が大きい。
- **スペースウェザリング**: 太陽風や微小隕石により表面が変質する現象。リュウグウの表面は「日焼け」している。
- **イオンエンジン**: キセノンガスをイオン化して高速で噴射する低推力・高効率の推進機。長期間連続運転で加速する。
- **プランタリーディフェンス(Planetary Defense)**: 小惑星・彗星の地球衝突を防ぐ取り組み。拡張ミッションの目的のひとつ。
- **高速自転小惑星(Fast Rotator)**: 自転周期が非常に短い(数分)小惑星。遠心力が重力を上回る特異な環境を持つ。
- **トリフネ(Torifune)**: 2001 CC21の日本名。はやぶさ2拡張ミッションで2026年7月にフライバイ探査した小惑星。

## ミッション・装置用語

- **サンプルリターン**: 探査機が天体の物質を採取して地球に持ち帰るミッション形式。
- **タッチダウン(TD)**: 探査機が小惑星表面に接触すること。TD1(1回目=表面)、TD2(2回目=地下物質)。
- **ホームポジション(HP)**: 高度約20kmのリュウグウ上空の定位置。ここから観測・運用を行う。
- **衝突装置(SCI)**: 火薬で2kgの銅弾を約7.2km/sに加速し、人工クレーターを作る装置(世界初)。
- **おむすびころりんクレーター**: SCIで2019年4月5日に作られた直径約14.5mの人工クレーターの通称。
- **ターゲットマーカ(TM)**: タッチダウンの目印として表面に投下する反射材入りの小球。
- **ONC(光学航法カメラ)**: 望遠(T)1台+広角(W1/W2)2台の計3眼。航法と科学観測の両方に使用。
- **LIDAR(レーザ高度計)**: レーザパルスの往復時間から距離を測る装置。地形データにも使用。
- **TIR(熱赤外カメラ)**: 表面温度分布を撮影し、熱慣性を調べる。
- **NIRS3(近赤外分光計)**: 3μm帯の吸収から含水鉱物や有機物を検出。
- **MINERVA-II**: リュウグウ表面でホッピング移動する自律小型ローバ。II1(イブー/アウル)、II2。
- **MASCOT**: ドイツDLR・フランスCNESが開発した小型着陸機。約17時間の観測を実施。
- **MASCAM**: MASCOT搭載カメラ。地表のクローズアップ画像を撮影。
- **CAM-H**: サンプル採取の様子を撮る小型モニタカメラ。「リュウグウの花吹雪」映像を撮影した。
- **DCAM3**: SCI実験時に分離し、衝突の様子を撮影した小型カメラ。
- **帰還カプセル**: サンプルを地球に届ける再突入カプセル。約12km/sで大気圏に再突入。
- **キュレーション**: 回収した試料を汚染から守り、記載・管理・配分する一連の作業。
- **拡張ミッション(はやぶさ2♯)**: メインミッション後の追加ミッション。トリフネ・フライバイを経て2031年に1998 KY26へ。

## データ・技術用語(サイト構築に関わるもの)

- **DARTS**: JAXA宇宙科学研究所の宇宙科学データアーカイブシステム。はやぶさ2の全科学データが公開されている。
- **PDS4**: Planetary Data System version 4。惑星科学データの国際標準形式。DARTSのはやぶさ2データはPDS4バンドルとして公開。
- **SPICEカーネル**: 探査機の軌道・姿勢・時刻系などを記録したデータ群。観測条件の再現に使用。
- **DSK(Digital Shape Kernel)**: SPICEの3D形状データ形式。リュウグウの形状モデルがこの形式で公開されている。
- **SfM / SPC**: 形状モデル作成法。Structure-from-Motion(ステレオ視)とStereophotoclinometry(陰影も利用)。
- **ONC L2A/L2B/L2C**: ONC画像の処理レベル。生データ→部分較正→較正済み。
- **ONC-T / ONC-W1 / W2**: ONCの望遠・広角カメラ。フィルタはul, b, v, w, x, p, hy等のバンド。
- **GeoTIFF**: 地理情報付きのTIFF画像形式。リュウグウのベースマップ等はこの形式でも公開。
- **Three.js / GLB / glTF**: Webで3D表示するための主要技術・形式。
