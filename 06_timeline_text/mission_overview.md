# はやぶさ2ミッション概要・探査機仕様

出典: JAXA/ISAS公式資料(https://www.isas.jaxa.jp/missions/spacecraft/current/hayabusa2.html 等)

## ミッションの目的

- 小惑星リュウグウ(C型=炭素質)からサンプルを採取して地球に持ち帰る(サンプルリターン)
- C型小惑星は水や有機物を多く含み、地球の水の起源や生命の原材料を探る手がかり
- 「はやぶさ」が探査したイトカワ(S型)とは異なるタイプの小惑星を探査
- 小惑星表面に人工クレーターを作り、地下物質を採取する世界初の挑戦
- 将来の宇宙探査に向けた技術実証(イオンエンジン、自律航法、高精度着陸等)

## 探査機仕様

| 項目 | 値 |
|---|---|
| 名称 | はやぶさ2 (Hayabusa2) |
| 打上げ | 2014年12月3日 13:22:04(JST) H-IIAロケット26号機、種子島宇宙センター |
| 質量 | 約609 kg(打上げ時、燃料含む) |
| 寸法 | 約 1.0 m × 1.6 m × 1.25 m(本体)、太陽電池パドル展開時 約 6 m |
| 電源 | 太陽電池(約2.6 kW @1AU)＋リチウムイオン蓄電池 |
| 推進 | イオンエンジン(μ10)4基(同時運転は最大3基)＋化学スラスタ(RCS) |
| 通信 | X帯 平面アンテナ2面(はやぶさのパラボラから変更し、着陸機を搭載可能に) |
| 探査方式 | 地球スイングバイ＋イオンエンジンによる往復飛行 |

## 主要ミッション機器(搭載装置)

| 装置 | 内容 |
|---|---|
| サンプル採取装置 | タッチダウン時に射出するタンタル弾で表面物質を捕集(サンプルホーン) |
| 地球帰還カプセル | 再突入カプセル(熱防御シールド、サンプルコンテナを内蔵) |
| 衝突装置(SCI) | 2kg銅弾を火薬で加速し、小惑星に人工クレーターを作る装置(世界初) |
| 小型搭載カメラ(CAM-H) | サンプル採取の様子を記録するモニタカメラ |
| 光学航法カメラ(ONC) | 望遠(T)、広角(W1/W2)の3眼。航法・科学観測 |
| レーザ高度計(LIDAR) | リュウグウまでの距離測定・地形データ取得 |
| 近赤外分光計(NIRS3) | 表面の含水鉱物・有機物の観測(波長3μm帯) |
| 熱赤外カメラ(TIR) | 表面温度・熱慣性の観測(8-12μm) |
| 小型ローバ MINERVA-II1 | リュウグウ表面をホッピング移動する自律ローバ2台(イブー/アウル) |
| 小型ローバ MINERVA-II2 | 軌道投入・着地実験を行うローバ |
| 小型着陸機 MASCOT | DLR/CNES製。カメラ(MASCAM)・熱放射計(MARA)・磁力計等を搭載 |
| ターゲットマーカ(TM) | 反射材入りの小球。着陸目印として投下 |

## 運用の様子(サイト演出のヒント)

- ホームポジション(HP): 高度約20kmのリュウグウ上空の定位置。ここから各種観測
- BOX-C/BOX-A運用: 低高度・上空観測の往復
- タッチダウンは数cm/sの低速降下。狙いはメートル単位
- CAM-H映像: タッチダウン時に砂煙(花吹雪)が上がる様子
- SCI運用: 探査機はリュウグウの裏側に退避し、DCAM3で衝突の様子を撮影
- 地球帰還: カプセルのみ大気圏再突入(約12km/s)。本体は速度を落とさず通り過ぎ拡張ミッションへ

## 拡張ミッション(はやぶさ2♯)

- 2020年12月の地球帰還後、本体は航行を継続
- 残存するイオンエンジン燃料(キセノン)を活用
- 2026年7月5日: 小惑星トリフネ(2001 CC21)フライバイ(表面から約400m、太陽系天体フライバイ最小距離の世界記録。LIDARによる世界初のフライバイ時レーザ測距にも成功)
- 2027年・2028年: 地球スイングバイ
- 2031年: 高速自転小惑星1998 KY26(直径約11m、自転約5.4分)へ到着予定
- 目的: 太陽系長期航行技術の進展、高速自転小型小惑星の探査、プランタリーディフェンス(地球衝突対策)に資する科学・技術の獲得
