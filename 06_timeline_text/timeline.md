## 初期分析・研究成果(主なもの)

| 日時 | 出来事 | 補足 |
|---|---|---|
| 2021-12-21 | 初期記載の結果: リュウグウは水・有機物に富む始原的な小惑星と判明 | 試料のバルク密度・反射スペクトルが小惑星全体平均と一致し、代表試料であることを確認。 |
| 2022-02-11 | 「リュウグウの花吹雪」— CAM-Hが捉えた表層粒子の振る舞いを解明 |  |
| 2022-02 | 初期分析(化学分析チーム): 10種以上のアミノ酸を含む多様な可溶性有機物を検出 | 生命の原材料となりうる有機物が小惑星に存在することを実証。 |
| 2022-06-10 | 初期分析: リュウグウの物質はCIコンドライト(イヴナ型隕石)に最も類似 | 地球上の隕石が経験した加熱・風化を受けていない最も始原的な太陽系物質。 |
| 2022-08 | リュウグウは太陽系外縁部で生まれた天体由来と判明(多機関連携分析) |  |
| 2022-10-21 | 世界初の小惑星からの「ガスサンプル」分析結果を公表(希ガス・窒素同位体) | サンプルコンテナ内の気体を採取・分析し、リュウグウ揮発性物質の起源と表層進化を解明。 |
| 2023-02-24 | 初期分析: 可溶性有機分子と黒い固体有機物(マクロ有機物)の詳細を公表 |  |
| 2023-03 | リュウグウ試料からウラシル(核酸塩基)とナイアシン(ビタミンB3)を検出 | 生命関連分子が小惑星上で生成されていたことを示す重要な発見。 |
| 2024-09-06 | マグネシウム同位体分析により始源天体における鉱物・水の変遷を解明 |  |
| 2024-11-22 | リュウグウの砂つぶから塩の結晶を発見 — 海洋天体とのつながりを示す手がかり |  |
