# RYUGU: リュウグウは、触れる。

はやぶさ2が持ち帰ったデータで、小惑星リュウグウへ降り立つ Web サイト(非公式のファンサイト)。
最小限の画面の裏で、軌道・自転・影・温度をその場で計算して描きます。

## 動かす

```
cd site
python3 -m http.server 8000     # → http://localhost:8000/
```

ビルド工程はありません。ES モジュールと WebGL2 だけで動きます(three.js などの外部ライブラリなし)。

## 裏側で計算していること

| 何を | どう |
|---|---|
| 探査機・地球・リュウグウの位置 | SPICE SPK(DAF)を自前で読み、チェビシェフ/ラグランジュ補間(`tools/ephem.py` で事前計算、`js/ephem.js` で補間) |
| リュウグウの自転 | 極の向きと自転速度から、毎フレーム回転行列を計算(`js/ephem.js`) |
| 太陽の向き・距離・光の遅れ | 暦から毎フレーム |
| 影 | 太陽の向きから 2048² のシャドウマップを描き直し |
| 表面温度(TIR) | 1次元の熱伝導モデル。熱慣性×太陽高度×時角の 1,680 通りを Worker で解き、GPU の頂点シェーダで補間(`js/thermalcore.js`) |
| LIDAR | 実測の測距点 396,649 点。取得時刻に合わせて現れる |
| 試料 | 顕微鏡画像と FTIR スペクトルは分析チーム公開データ。浮かぶ粒子は演出 |
| 状態の保存 | URL(`?time=…&i=…&lat=…&lon=…&alt=…`) |

画面右上の「裏側」で、いま動いている値を見られます。

## 実測と、計算で補ったもの

- 実測: 軌道、形状モデル、ONC の画像と地図、LIDAR の測距点、試料の顕微鏡画像とスペクトル
- 推定: 温度(熱モデルの推定値で、観測値ではない)
- 仮定: 探査機の姿勢(ホームポジションの向きを仮定)、星空(手続き生成)
- 補間: 探査機位置のデータが無い区間は、公表されたタッチダウン地点につないでいる。人工クレーター作成時(SCI)の探査機位置と、SPK の終了(2023年9月)以降は、探査機を描かない
- 演出: 粒子の動き、カメラの遷移

科学的な再現と、見せるための演出は区別しています。正確な値は公式の資料を参照してください。

## データの再生成

`tools/` の Python スクリプトが、リポジトリ上位のデータ(`01_`〜`11_`)から `site/data/` を作ります。
`daf.py`(SPK 読み取り)、`ephem.py`(軌道)、`prep_geometry.py`(形状・LIDAR)、`prep_assets.py`(地図・画像・試料・探査機モデル)。
