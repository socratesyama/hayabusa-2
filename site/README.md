# Ryugu Pencil Atlas: 観測データから、リュウグウを描く。

はやぶさ2の観測データから作った点群を、紙の上の鉛筆画として描く、非公式のファンサイトです。
黒い宇宙の版は、別ブランチ `ryugu-site` にあります。

## 動かす

```
cd site
python3 -m http.server 8000     # → http://localhost:8000/
```

ビルド工程はありません。ES モジュールと WebGL2 だけで動きます(外部ライブラリなし。手書き風の見出しにだけ Google Fonts の Klee One を使い、読み込めないときは明朝系の字体になります)。

## 見かた

- 鉛筆: 約31.6万点を、点ごとに短い線として毎フレーム描きます。画像フィルターではありません
- 点群: 同じ点を、陰影をつけた点としてそのまま描きます
- 形成: バーを動かすと、散らばった点が自転しながら集まり、リュウグウの形になります。背景は黒くなり、星が出ます
- 光: 製図灯(カメラに対して固定)と、太陽の向き(暦から計算)

## 実測と、計算で補ったもの

- 実測(OBSERVED): 点群のもとになった形状、ONC画像、試料の画像とスペクトル、できごとの日時
- 計算(DERIVED): 点の座標を1/5に間引いたもの、地図から取った明るさ、地点の3D位置、太陽の向き
- 推定(ESTIMATED): 法線(近傍の点から推定)
- 説明用(ILLUSTRATIVE): 鉛筆の線、断面の模式図、形成の動きと星

隠れた線を消すために、SPC形状(200k面)を画面に出さずに使っています。点群とは別のモデルのため、数m(中央値2.6 m、最大25 m)の食い違いがあります。
ONC画像は撮影範囲の情報がないので、3D上の位置とは結びつけていません。

## データの再生成

`tools/prep_pencil.py` が、リポジトリ上位の `10_pointclouds/sfm_3m/` から `data/pencil.bin` を作ります。
