# 科学値監査メモ

## TD1地点の形状半径 — 2026-11-08に再検証

対象座標は Nakamura et al. 2022 の L08-E1 (`4.3°N, 206.47°E`)。運用メッシュは `01_shape_models/ryugu_shape_spc_49k_v20200323_web.obj` (49,152面、SPC v20200323) である。SRC001に登録された200k面モデルは元データ／高解像度資料として保持し、TD1の実運用・生成処理に使用するのは49k面モデルである。49k結果を「200kモデルから直接計算」とは表現しない。

### 数学的根拠

位置ベクトル `x` が形状モデルの中心を原点とし、単位方向 `d` を緯度経度から作ると、中心から外向きのレイは `x(t) = 0 + t d, t > 0`。各三角形との正の交差距離 `t` のうち最小値が、レイが最初に表面へ到達する距離である。`max(t)` は、非凸形状や複数の交差面がある場合に、表面を通過した後の遠い交点を選び得る。したがって一般の「最初の交差」は最小正距離で選ぶ。

検証により旧コードには、さらに原点の実装誤りがあった。Möller–Trumbore式のオフセットを `d - v0` としており、中心 `0` ではなく方向ベクトル `d` をレイ原点としていた。`d` は単位長なので、この誤りが交点距離に約1 m加算される／減算される。修正版は原点を明示的なゼロベクトルとし、正の交点を全件求めて最小を採る。

### 測定結果・影響

| 項目 | 半径 |
|---|---:|
| 旧JSONのTD1表面半径（旧式・2桁丸め） | 508.59 m |
| 旧原点誤りを独立に再現した距離 | 508.585369 m |
| 修正版の49k中心原点レイ（独立スカラー法） | 509.585369 m |
| 修正版JSONのTD1表面半径（2桁丸め） | 509.59 m |
| 修正差（表示丸め後） | +1.00 m |

実形状モデルのTD1方向では前方の交点は1件だったため、この地点で `min` と `max` の選択は結果を変えない。+1.00 mの差はレイ原点の誤りによる。`min` 選択が必要な数学的性質は、複数交差を作る入れ子の閉じた立方体(非凸ケースの交差検査用)で別途検証した。

接地時刻 `2019-02-21T22:29:10Z` の再生成行は `r=511.59 m`, `alt_local=2.00 m`。公開CAM-H高度の1.0mは探査機底面から表面までであり、中心位置へ底面—中心オフセット1.0mを加えるため、形状表面からの中心高度2.0mと整合する。半径と位置の双方を再生成し、中心高度は旧表と同じ2.0mに保たれた。

TD1地点のレイ距離は、ベクトル化した三角形交差計算に加え、別実装のスカラー平面・重心座標法でも照合した。両者は `509.585369 m` で一致する。自動テストは49k形状モデルそのものを読み込んでこの照合を行う。

## TD1位置テーブルのprovenance・不確かさ

`td1_descent_positions.json` はhpk SPK欠損区間を、spc_pos v02の離散航法解およびJAXA公表資料の時刻・高度アンカーから構成する再構成テーブルであり、SPK直接値だけからなる軌道ではない。各行に `grade`, `src`, `method`, `uncertainty: null`, `uncertainty_note` を付け、生成器・運用形状モデル・接地地点の交点計算法もトップレベルに記録する。

A/B/C/Dは**証拠・生成根拠の分類であり、精度や正確度の順序・数値ではない**。位置不確かさの根拠ある定量値を取得できていないので数字は付与しない。特にBの行は公表高度を使う一方、位置はTD1座標から再構成している。姿勢CKは位置テーブルに含まれず、姿勢は取得・検証したデータとして扱わない。

SPICE欠損区間の表は再現可能で、次のコマンドで再生成できる。実行には `numpy`, `scipy`, `spiceypy` とリポジトリ収録SPICEカーネルが必要。

```bash
cd 12_site_data/conversion
python3 build_td1_descent_table.py \
  --spice-dir ../../03_spice \
  --shape-obj ../../01_shape_models/ryugu_shape_spc_49k_v20200323_web.obj \
  --out ../td1_descent_positions.json
```

## 自動検証・CI

`python -m unittest discover -s 12_site_data/tests -v` はCIのprecompute/buildより前に実行する。現時点の科学テストは以下を検証する。

- 凸立方体の中心→表面レイで最初の交差を返す。
- 入れ子の閉じたメッシュに複数の正交差があるとき、最小の正距離を選ぶ。
- TD1の49kメッシュで独立スカラー交差法と一致し、旧式の1m原点オフセットを検出する。
- 再生成データのTD1地点半径、接地時刻・中心高度、アンカー収録、時刻一意性、行ごとのmethodと不確かさフィールドを検証する。
